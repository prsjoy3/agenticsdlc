# Specs for Building New Features

The first capability is specs for building new features. At a minimum, a specification should contain:

- Intent
- Requirements
- Acceptance criteria in Given/When/Then format
- Any other additional context

Use conductor mode to arrive at this. Human involvement is most needed here; at this moment, full automation is not possible in this area. Be in conductor mode to come up with specs, and then switch to orchestrator mode and manage the outer loop.
